# v1.2.0-beta.1 — Draft Release Notes

LOCAL PREPARATION ONLY. Intended GitHub owner: Breathe4me. Publication has not been authorized. Do not create a Release until RELEASE_DECISION.md has all necessary evidence and the maintainer approves.

This Beta combines the approved WebView2 UI with existing Python/SQLite services: read-only Canvas synchronization, local tracking, optional Windows/PushPlus reminders and optional AI BYOK. Warm Sage/Soft Pink and Chinese/English are retained. The TLS companion resource fix is included.

Limitations: student API scope varies; Quiz endpoints may be disabled; incomplete coverage is reported. Local completion is not remote submission. Official Canvas records and course deadlines remain authoritative. No guarantee of discovering every task or replacing manual checks. No automatic submission is implemented.

AI uses your own provider key and may incur third-party fees. PushPlus is a third-party WeChat service; API acceptance differs from confirmed receipt. Scheduling and real notification delivery require Windows manual acceptance. First-run setup uses the Settings page; a dedicated wizard is not implemented.

Planned assets: CanvasDeadlineAgent-v1.2.0-beta.1-Setup.exe, CanvasDeadlineAgent-v1.2.0-beta.1-Portable.zip, CanvasDeadlineAgent-v1.2.0-beta.1-Source.zip, SHA256SUMS.txt. They are production-default local candidate builds, not Synthetic QA defaults and not public-approved releases. Check hashes and do not override security detections.
